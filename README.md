# Sunrise Student Hostel

A clean, responsive single-page hostel website for a fictional student hostel. It helps students and parents view rooms, facilities, food, rules, support contacts and location information.

## Features

- Sticky responsive navigation
- Hostel hero banner and calls to action
- Room cards with availability badges
- Facilities, weekly food menu and hostel rules
- Complaint/support information and HTML-only form
- Contact details and Google Maps embed
- Flexbox-only responsive layout

## Upload to GitHub

1. Create a new repository on GitHub.
2. Open a terminal inside this project folder.
3. Run:
   ```bash
   git init
   git add .
   git commit -m "Create hostel management website"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPOSITORY_URL
   git push -u origin main
   ```
4. If GitHub asks for login, complete the browser or token sign-in.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Click **Settings**.
3. Click **Pages** in the left sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the **main** branch and the **/(root)** folder.
6. Click **Save**.
7. Wait a few minutes and open the URL shown on the Pages page.
